# QuickChat (PROG5121 PoE)

Maven project - open in NetBeans with File > Open Project.
Requires JDK 25 (set in pom.xml). Run: `mvn test` (tests) or run `com.mycompany.main.Main`.

Menu: 1 Send, 2 Sent-messages report, 3 Quit, 4 Load test data, 5 Longest sent message,
6 Search by recipient, 7 Delete by hash, 8 Read messages.json.

Attribution: JSON reading uses java.nio.file.Files and java.util.regex (Java SE API, Oracle).
